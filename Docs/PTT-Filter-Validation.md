# PTT 名單與關鍵字驗收

文件建立：2026-11-24。範圍：codex/PTT-Filter 分支的 PCMan LITE。規格見 [PTT-Filter-Spec](PTT-Filter-Spec.md)，使用說明見 [Readme](../Readme.md)。
自動測試（`Tests/bin/<組態>/UnitTests.exe` 的「PTT filter」）已通過 40 項；以下為尚待人工確認的項目。

## 準備

1. 使用剛建置的同一組態執行檔，例如 `Lite/Debug/PCMan/PCMan.exe`。Debug 與 Release 的設定檔分開存放在各自的 `PCMan/Config/PttFilter.dat`。
2. 正式發布前不相容舊設定檔：舊版本的 `PttFilter.dat` 會被忽略，清單從空白開始，需重新設定。
3. 字碼與尺寸：Big5、80×24 為主；有餘力再以 UTF-8 重測 A、C。
4. 不需要發文、推文或改個人設定；只瀏覽看板。

每項記錄：通過／失敗／N/A、站台（PTT 或 PTT2）、連線方式（telnet 或安全連線 wss），失敗時附截圖或複製的畫面文字。

## A. 設定視窗（選項 →「PTT／PTT2 名單與關鍵字…」）

| # | 操作 | 預期 |
| --- | --- | --- |
| A1 | 開啟視窗 | 標題為「PTT／PTT2 名單與關鍵字」；游標停在新增列的輸入框；套用於三項預設全勾 |
| A2 | 類型「帳號」，輸入一個 ID，按 Enter | 加入清單並選取，輸入框清空，視窗不關閉；清單顯示「列表、內文、推文」「整篇」「預設」 |
| A3 | 再輸入同一 ID 的大小寫變體，按 Enter | 紅字「清單中已有相同的規則」，不加入 |
| A4 | 輸入 `1abc`、`a`、`ab_c` | 紅字帳號格式錯誤，不加入 |
| A5 | 三個勾選全取消後按 Enter | 紅字要求至少勾選一個套用位置，不加入 |
| A6 | 類型切換帳號／關鍵字，並勾選或取消「內文」 | 帳號時內文遮罩固定為灰色「整篇」；關鍵字且勾選內文時可選「關鍵字／單行」，取消內文時變灰 |
| A7 | 雙擊清單項目，修改勾選與遮罩後按確定 | 小視窗帶入原值；清單更新；未勾內文的規則在「內文遮罩」欄顯示「—」 |
| A8 | 多選後按 Delete | 全部刪除 |
| A9 | 搜尋框輸入部分文字、類型篩選 | 清單只顯示符合項目，右上角顯示「共 N 條，顯示 M 條」 |
| A10 | 點欄位標題兩次 | 依該欄排序，第二次反向 |
| A11 | 點「標色字色」「底色」 | 彈出 8×2 色塊與「保留原色」；選後按鈕與右側預覽立即更新 |
| A12 | 按「取消」後重開 | 未儲存的變更全部不見 |
| A13 | 按「儲存」後關閉程式再開 | 規則、勾選、遮罩與顏色都保留 |

## B. 文章列表

先在任一看板挑一位作者 X、一個標題字詞 K，建立：帳號 X（三項全勾、預設）、關鍵字 K（只勾列表、標色）。

| # | 操作 | 預期 |
| --- | --- | --- |
| B1 | 進入看板列表 | X 的文章除編號外都被遮蔽（推文數、日期、作者、標題）；編號仍看得到 |
| B2 | 同上 | 標題含 K 的文章除編號外都標色 |
| B3 | 找推文數為「爆」或兩位數、日期為 10～12 月的列 | 仍正確遮蔽，編號保留 |
| B4 | 把游標移到被遮蔽的列 | 最左側的游標標記（`●` 或 `>`）仍看得到 |
| B5 | 置底文章（★）與轉錄（轉）、回覆（R:）文章 | 規則同樣生效；置底文章的 ★ 保留 |
| B6 | 分類括號內含 K 的文章（例如 `[K]`） | 不受影響（分類不參與比對） |
| B7 | 編輯 X 的規則，只勾「推文」 | 列表中 X 的文章恢復正常顯示 |
| B8 | 上下移動游標、翻頁 | 遮蔽跟著正確更新，無殘影 |

**若 B1～B4 失敗**：請在列表畫面用滑鼠選取 3～5 列（含標題列）複製，貼給開發者，這是修正辨識格式的依據。

## C. 閱讀文章與推文

建立：帳號 Y（只勾推文、隱藏）、關鍵字 W（只勾推文、星號）、關鍵字 V（只勾內文、星號、內文遮罩「關鍵字」）。Y、W 取自某篇有推文的文章，V 取自某篇文章的正文。

| # | 操作 | 預期 |
| --- | --- | --- |
| C1 | 從列表進入 X 的文章 | 檔頭作者、標題與整篇正文遮蔽；別人的推文正常 |
| C2 | 進入有 Y 推文的文章 | Y 的帳號與發言隱藏；開頭的推／噓／→ 與行尾日期時間仍可見 |
| C3 | 推文含 W | 該則推文的帳號與發言變星號；推噓符號與日期時間仍可見 |
| C4 | 正文含 V | 只有 V 這幾個字變星號，同一行其他字照常 |
| C5 | 把 V 的內文遮罩改為「單行」 | 含 V 的整個畫面列變星號 |
| C6 | 推文或列表標題含 V | 不受影響（V 只勾內文） |
| C7 | 進入長文章後直接按 End 跳到最後一頁 | C2、C3 仍生效 |
| C8 | 在 C1 的文章按 End | 作者 X 的正文仍遮蔽 |
| C9 | 選取被遮蔽的文字並複製 | 剪貼簿得到完整原文 |
| C10 | 標色、星號、隱藏三種效果各試一次；標色時把字色設成接近底色 | 欄位位置不變；中文字星號佔兩格；標色可達到不易看清的效果 |
