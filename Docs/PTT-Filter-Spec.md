# PTT／PTT2 黑名單與關鍵字顯示過濾

建議 Issue 標籤為 `ready-for-agent`。

## Problem Statement

閱讀看板時，使用者希望略過特定帳號的文章或推文，也希望能降低劇透等內容的可見度。不同情境需要不同強度的處理，但仍需保留終端機的欄位位置、原文與操作線索。

## Solution

在 PTT 與 PTT2 的文章列表和閱讀畫面提供 ID 黑名單與關鍵字過濾。兩站所有看板共用設定。每條規則可選文章、推文或兩者，並可跟隨共用遮蔽方式或個別指定。初始使用等寬星號。

## User Stories

1. 身為兩站的讀者，我希望在 PTT2 測好的規則能直接用在 PTT，以便只維護一份清單。
2. 身為讀者，我希望分開管理 ID 與關鍵字，以便精準封鎖帳號，同時搜尋內文中的字詞。
3. 身為讀者，我希望 ID 忽略英文大小寫並比對完整帳號，以免封鎖名稱相似的人。
4. 身為讀者，我希望直接輸入關鍵字就搜尋包含該詞的內容，以便快速建立常用規則。
5. 身為讀者，我希望能將關鍵字切換為「完全相同」，以便只處理整個欄位剛好符合的內容。
6. 身為讀者，我希望每條規則都能選文章、推文或兩者，以便只遮蔽我選定的內容。
7. 身為讀者，我希望未指定方式的規則跟隨共用預設，以便一次調整多條規則。
8. 身為讀者，我希望個別規則可指定固定方式，以便保留例外。
9. 身為讀者，我希望在列表中遮蔽黑名單作者與標題，同時看得到文章編號和推文數，以便繼續瀏覽。
10. 身為讀者，我希望開啟黑名單作者的文章時遮蔽作者、標題與正文，以便仍可閱讀其他人的推文。
11. 身為讀者，我希望推文者 ID 命中時遮蔽帳號與發言，以便略過該人的推文。
12. 身為讀者，我希望只有關鍵字命中時保留推文者 ID，以便知道發言者是誰。
13. 身為讀者，我希望標題命中只處理標題，正文和推文各自比對，以便繼續閱讀其餘內容。
14. 身為讀者，我希望跨越可確認自動折行的關鍵字也能命中，以免劇透因排版而漏出。
15. 身為讀者，我希望星號與隱藏都保留原來的文字位置，以便照常用游標瀏覽。
16. 身為讀者，我希望標色可單獨改字色或底色，以便保留看板原有的配色線索。
17. 身為讀者，我希望多條規則重疊時較強的遮蔽優先，以免標色意外顯露要隱藏的文字。
18. 身為讀者，我希望複製可取得完整原文，以便保留或轉用原始內容。

## Implementation Decisions

* 建立連線時依網址的主機名稱辨識 PTT2，結果沿用至該連線結束。登入後繼續辨識畫面與目標欄位，僅在可辨識的文章列表或閱讀畫面套用過濾。無法辨識畫面或欄位時，該處照常顯示原文。
* 顯示過濾以已辨識的站台、畫面與欄位為界。文章關鍵字只比對標題與正文。推文關鍵字只比對發言。分類、板名、時間、推噓符號和頁尾不參與關鍵字比對。
* 關鍵字預設「包含」，也可選「完全相同」。忽略英文大小寫與用來對齊的填補空白，保留字詞間的空格與標點。推文的時間及帳號均不屬於發言文字。
* 正文一般逐畫面列比對。可確認為同一段自動折行的列接續比對，遮蔽命中文字涉及的完整畫面列。遇到手動換行或來源不明時分列比對。使用者功能說明須保留此判定方式與可能漏判的例子。
* ID 命中時依畫面處理作者或推文者的欄位。關鍵字命中時處理整個標題、整則推文發言或命中的正文列。各欄位分別以隱藏、星號、標色的優先順序合併結果，順序不受規則建立時間影響。
* 隱藏使用每格當前底色作為字色。星號按終端欄寬替換，雙欄中文字顯示兩個星號。標色共用一組前景色和底色，各自可選保留原色或終端機色盤中的顏色。
* 遮蔽只影響顯示。保留終端原文與列、欄位置，複製隱藏或星號遮蔽的選取範圍仍得到原文。

## Testing Decisions

* 在同一條以主機名稱辨識的 PTT2 連線上，登入後從文章切換到編輯器，再返回文章。三個畫面都顯示相同關鍵字，確認只在文章中套用遮蔽。另回放無法辨識的畫面，確認即使出現該關鍵字也會保留原文。
* 以實際 PCMan 視窗為主要驗收層級，沿用本機連線回放與剪貼簿測試做法。經設定介面建立規則，重播固定畫面，觀察文字、色彩、欄位位置及複製結果。測試應允許內部資料結構調整。
* 驗證 PTT 與 PTT2 共用規則、跨板生效，並切換到編輯器、站內信及其他 BBS，確認原文正常顯示。
* 用完整 ID、大小寫變體及相似 ID 驗證帳號比對。用標點、字詞間空格及對齊填補驗證兩種關鍵字模式。分別套用到文章、推文與兩者。
* 改動共用預設，確認跟隨預設的規則更新，個別指定的規則仍照指定方式顯示。以同一則推文同時命中 ID 與關鍵字，驗證帳號、發言可有不同效果，推噓符號和時間仍可讀。
* 用具有不同底色的中英文混排畫面，驗證隱藏、等寬星號與局部換色。選取同一段文字複製並比對原文。
* 將「暴」與「雷」分置相鄰兩列。可確認的自動折行應命中「包含『暴雷』」並處理兩列。手動換行及原因不明時應分列比對。捲動與重繪後重驗。

## Out of Scope

其他 BBS，以及 PTT／PTT2 的站內信、聊天室和編輯畫面。此版不包含每板獨立清單、萬用字元、正規表示式、任意 RGB 配色、移除終端列或過濾剪貼簿原文。

## Further Notes

PCMan 已可辨識遠端自動折行模式並處理右邊界。實作時需驗證畫面捲動、重繪與伺服器重新送出內容後，能取得哪些列的折行來源。不得僅依上一列填滿右邊界推定為自動折行。
