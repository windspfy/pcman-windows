## 列更新：原始來源仍是不可變 value

`EncodedRow` 的更新方法回傳新來源列；範圍錯誤、放不下完整替代文字、配置失敗或超過每列 payload 額度時，不改原來源或已取得快照。
依 codebase-design 將寬字修復、來源分段、原始 byte／style 保存集中在同一個 Module，不讓各讀取端自行以 byte 算欄位；沒有新增第二套游標。

| Interface | 政策 |
| --- | --- |
| `ReplaceUtf8(columns, begin, end, replacement)` | 以 `[begin,end)` 格範圍替換；替代文字較短補空白，較長或裁切到字元則拒絕，不移動後續可見文字 |
| `ReplaceLegacy(..., decoder)` | 同一更新流程，以傳入的 legacy adapter 解碼來源與替代文字；不把 UTF-8 格數套到 Big5 |
| 空來源作 replacement | 清除選定格；全列清除同時刪掉隱藏後綴與孤立來源，避免之後換編碼又復活 |
| 覆寫／清除舊寬字任一半 | 移除完整舊字及附加字，未被替代文字佔用的另一半補預設空白，清掉舊顏色／link ID |
| `SliceUtf8`／`SliceLegacy` | 供內部列範圍搬移使用；保留完整字元的原始 bytes／style，切到半字則補空白維持格對齊。不同於使用者 `Text`／`RawText` 選半字時略過字元 |
| `CropUtf8`／`CropLegacy` | 明確、破壞性的右側裁切，只保留可容納的完整字元；裁掉的字元及其後綴不會因日後放大而復活。不是讀取投影，也不是完整終端 resize |

讀取窄投影仍不改來源；更新會考慮未完整呈現、但與目標範圍相交的寬字。
例如 `A中́B` 讀成兩欄時只呈現 `A` 及末格空白：改第一格保留未碰到的 `中́B`；改第二格則移除相交的整個 `中́`。
沒有碰到的隱藏後綴仍保存；全列清除／明確 crop 才會依上述政策刪除它。
主程式真正放大時不能把 `Crop` 當成唯讀投影呼叫，尤其不可藉此刪除僅因換錯編碼而暫時不可見的資料。

## 解碼分界不能只靠保留 bytes

新增 `Byte::boundaryBefore`，表示真正文字／控制或編輯分界，並非傳輸 byte，也不是第二個游標。
相同 bytes 在中間曾發生定位／文字結束時，不能因列資料重組就誤接成新字。
例如 `E4` 與 `B8 AD` 若原先被真正文字分界隔開，重新讀取時仍是無效子序列，不可自動合成「中」。

UTF-8 在分界完成舊前綴，結束零寬附著，再處理後續來源；legacy adapter 只取得該分界以前的來源長度。
覆寫／範圍複製保留既有分界，並隔開新接合的片段；原始 byte 值與逐 byte style 不轉碼。
分界也保存在列複製與快照內；讀取 UTF-8／Big5 不會消耗它。

**正式接收端仍待接入**：不能每個封包都設分界，也不能把一般 SGR 屬性切換當作定位。
將來啟用 CPR 時，純查詢也不得藉分界 flush 前綴、移動游標或取消待折行。
本輪沒有處理 ANSI／DCS／Telnet 串流，不將手動建立分界的測試誤稱為完整接收測試。

## 稀疏列儲存

`EncodedRowStorage` 以既有列配置的身分（`const void*`）保存非空來源，不解讀或解參考該指標。
未儲存的列視為空來源；32,767 個空歷史列不需配置 32,767 個格向量或原始空白向量。

| Interface／生命週期 | 資料層行為／正式接點要求 |
| --- | --- |
| `At`／`TrySet` | 唯讀取得來源／設定非空列；空來源釋放該身分。`At` 是參考，不能跨該身分的修改／回收保留，需快照時用 value copy |
| 外部列指標旋轉 | 來源跟著身分移動，不另複製 payload；可用於既有全頁／部分區域捲動，**實際 `LineFeed` 尚未掛接** |
| `Erase` | 回收／釋放列之前移除來源，避免記憶體位址重用讀到舊內容 |
| `Copy` | 整列來源深拷貝；包含每 byte style、解碼分界及隱藏後綴。複製空列會清空目的地 |
| `Move` | resize 換成新列配置身分時搬移；不複製 payload、不需要暫時加倍來源額度；覆蓋目的列只扣一次舊資料 |
| `Capture`／`Reset` | 最多 64 列的獨立來源快照／清空舊連線身分與用量；不是既有 DEC2026 已改用這個快照 |

儲存額度必須由 adapter 明確傳入：列數 1～32,767，來源 payload 總額度大於零；不是新增 UI 設定。
`TrySet`／`Copy` 額度不足回傳 false，不淘汰舊列、不悄悄轉碼或丟字；不合法身分／尺寸拋出例外。
payload 用量不等於 RAM：Byte 的 style／分界、map、投影及快照另有成本。
正式接入時仍須選定整體記憶體政策，處理拒絕更新的顯示／連線策略；**不可忽略回傳值、先改舊畫面或先推進游標**。
此 Module 沒有追蹤 URL 實體或延長 OSC 目標生命週期；正式同步／連結快照仍須一起整合。
