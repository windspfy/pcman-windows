PCMan
---
這是 PCMan BBS 用戶端的程式碼。PCMan Combo 已停止維護並自主要開發分支移除；
最後版本封存於 Git tag `combo-final`。

除 Lite 目錄下的 Rijndael.cpp 和 Rijndael.h 為 George Anescu 撰寫，
不是使用 GPL 授權以外，其餘程式碼皆是使用 GPL 授權。

因為授權問題，本專案無法包含圖形檔，各種圖示暫時以單色的 bmp 取代，
請下載舊版 PCMan 的 zip 檔，從中取出各 bmp 圖檔，並放到正確位置。

### PTT 與 PTT2 名單與關鍵字

從「選項」選單開啟「PTT／PTT2 名單與關鍵字」。名單可當黑名單（星號、隱藏）用，也可當關注名單（標色）用。帳號與關鍵字放在同一份清單，可用上方的搜尋框與類型篩選，點欄位標題可排序。在下方「新增規則」選擇類型、輸入內容、選擇效果，勾選套用於「列表」「內文」「推文」，按 Enter 或「加入」即加入清單；雙擊清單項目可編輯，按 Delete 可刪除（可多選）。完成後按「儲存」。兩站的所有看板共用設定。

* **帳號**比對完整帳號（英文字母開頭、2～12 個英數字），忽略大小寫。勾選列表時處理該作者文章在列表中的那一列；勾選內文時處理該作者文章的檔頭作者、標題與整篇正文；勾選推文時處理該帳號的推文。
* **關鍵字**只要包含就命中，忽略英文大小寫；標點和字詞間的空格會參與比對，畫面對齊用的填補空白會略過。勾選列表時比對標題（不含分類），命中就處理那一列；勾選推文時比對發言，命中就處理該則推文；勾選內文時比對標題與正文，「內文遮罩」可選只遮「關鍵字」本身或整個「單行」。
* 列表的一列被處理時，保留最左側的游標標記與文章編號，其餘（推文數、日期、作者、標題）都套用效果，讓人看得出這一列還在。推文被處理時，保留開頭的推／噓／→ 符號與行尾的日期時間，推文者帳號與發言都套用效果。
* **正文跨列比對**限於可確認的自動折行。例如「暴」在上一列末尾、「雷」在下一列開頭，若兩列屬於同一段自動折行的文字，「暴雷」就會命中，兩列都套用。遇到手動換行，或無法確認折行原因時，會分列比對，此時跨列的「暴雷」就不會命中。
* **效果**可選「預設」（使用共用設定的預設效果，初始為星號），也可逐條指定標色、星號或隱藏。隱藏會讓文字與當前底色相同；星號會保留原本欄寬；標色共用一組配色，字色與底色按鈕會直接顯示目前顏色，點開可從終端機的 16 色色盤選擇或保留原色，旁邊的預覽會即時顯示效果。同時調整字色與底色可用來醒目標示，也可讓文字變得不易看清。同一處命中多條規則時，依隱藏、星號、標色的順序優先套用。

遮蔽只改變畫面顯示，文字位置維持原樣。複製時會取得完整原文，包括畫面上已隱藏或換成星號的內容。

使用 Visual Studio 2026 建置
---

請安裝「使用 C++ 的桌面開發」工作負載，並包含下列元件：

* MSVC v143 x86/x64 建置工具
* 適用於 x86 的 MFC
* Windows 11 SDK 
* vcpkg

開啟 `PCMan.sln` 後可直接建置 `Debug|Win32` 或 `Release|Win32`。專案已啟用
vcpkg manifest，首次建置會自動下載及編譯相依套件。

也可以在 Developer PowerShell for Visual Studio 中執行：

```powershell
msbuild PCMan.sln /m /t:Rebuild /p:Configuration=Release /p:Platform=Win32
```

WebSocket 連線使用 Windows 內建的 WinHTTP，不需要額外部署 WebSocket、OpenSSL
或其他 TLS 程式庫；WSS 連線需要 Windows 8 以上。快捷鍵 JSON 讀寫使用
`nlohmann/json`，由 vcpkg manifest 自動還原。
